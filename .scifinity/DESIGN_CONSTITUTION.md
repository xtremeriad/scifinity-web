# SCIFINITY Design Constitution

Version: 1.0

## Objective

AI must improve SCIFINITY without destroying its established identity.

## Visual hierarchy

Every page should have:

1. clear primary purpose
2. obvious heading hierarchy
3. predictable navigation
4. focused primary action
5. readable supporting information

## Typography

Use the existing SCIFINITY typography system and tokens.

Do not introduce a new font family or arbitrary typography scale without justification.

Bengali text must remain readable on desktop and mobile.

## Color

Use existing design tokens.

New colors should be introduced only when they solve a documented design need.

## Layout

Prefer:

- consistent container widths
- predictable spacing
- responsive grids
- mobile-first adaptation
- adequate touch targets

## Motion

Motion should communicate:

- hierarchy
- state
- continuity
- feedback

Avoid motion that:

- delays access to content
- distracts from academic information
- causes excessive CPU/GPU use
- creates accessibility problems

## Components

Reuse existing components before creating new ones.

A new component should have a clear reusable purpose.

## Images

Images should be optimized for web delivery.

Do not ship original photographic masters when a smaller delivery asset is sufficient.

Use meaningful alt text.

## AI-generated graphics

AI may propose graphics, but public-facing brand assets require owner approval.

Do not silently replace logos, signature visuals, or identity assets.

## Accessibility

Design changes should consider:

- keyboard access
- focus visibility
- semantic structure
- contrast
- reduced motion
- readable text sizing
- touch target size
- alt text
