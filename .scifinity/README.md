# SCIFINITY AI Foundation

This directory contains the governance layer for the SCIFINITY AI website agent.

The intended progression is:

```text
Phase 1
Audit
  ↓
Phase 2
Propose
  ↓
Phase 3
Modify + test
  ↓
Phase 4
Preview deployment
  ↓
Phase 5
Controlled autonomous maintenance
```

The AI should always follow `AGENTS.md`.

These files are policy/instruction files, not credentials.

Do not put API keys, Firebase private keys, service-account credentials, or passwords in this directory.
